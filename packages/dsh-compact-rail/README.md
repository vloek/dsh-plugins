# dsh-compact-rail

Возвращает узкую полосу иконок в десктопный DeepSeek Harness под Windows.

В оболочке Windows приложение сворачивает левый сайдбар до нуля и переносит кнопку сворачивания и «Новую сессию» в заголовок окна. В браузерной сборке вместо этого остаётся полоса иконок шириной 56px. Плагин даёт десктопу ту же полосу: **Ctrl+B** сворачивает сайдбар до иконок, а не прячет его целиком. Иконки панелей и настройки остаются под рукой, кнопка сворачивания остаётся в левом верхнем углу.

На macOS, Linux и в веб-версии плагин ничего не делает.

## Настройки (`cordis.patch.yml` профиля)

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `startCollapsed` | `true` | Один раз сворачивает сайдбар до полосы при запуске приложения. DSH забывает состояние сайдбара при каждой перезагрузке |
| `hideBrand` | `false` | В развёрнутом сайдбаре прячет строку с логотипом и подписью сборки |

```yaml
- id: compact-rail
  config:
    startCollapsed: false
    hideBrand: true
```

## Устройство

Только CSS и немного JavaScript в браузерной части (`lib/client.js`). Плагин переписывает первую колонку сетки окна с 0px на 56px, пока сайдбар свёрнут, и отменяет правила, которые в оболочке Windows прячут иконки. Хэшированный префикс CSS-классов сайдбара он читает на лету из тега `<style data-plugin-css>`, поэтому обновления DSH его, скорее всего, не сломают.

Проверка без запуска приложения: `node test/run.mjs`.
