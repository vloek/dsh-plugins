# dsh-slim-caption

Компактная полоса заголовка для десктопной DeepSeek Harness под Windows.

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `hideMenu` | `true` | Скрывает меню «Application / Edit» |
| `mergeHeader` | `true` | Поднимает строку заголовка беседы (название, режим, статус, кнопки справа) в полосу заголовка окна. Это та же строка, а не копия, поэтому ничего не дублируется, а по высоте освобождается одна строка |
| `transparentControls` | `true` | Делает прозрачным фон под кнопками «свернуть / развернуть / закрыть», и они ложатся поверх интерфейса и скина |
| `f11Fullscreen` | `true` | F11 переводит всё окно в полноэкранный режим, повторное F11 возвращает обратно. В полноэкранном режиме полоса заголовка и кнопки Windows исчезают |
| `escKeepsFullscreen` | `true` | В полноэкранном режиме Esc достаётся приложению: закрывает окна, останавливает генерацию и не выбрасывает из полноэкранного режима. Выход — по F11 |

Пустое место в поднятой строке по-прежнему перетаскивает окно, двойной клик по нему разворачивает окно.

Полноэкранный режим включается через HTML Fullscreen API: Electron сам разворачивает окно на весь экран. Обычно Chromium выходит из такого режима по Esc. Чтобы этого не было, плагин через Keyboard Lock API (`navigator.keyboard.lock(["Escape"])`) отдаёт Esc странице, пока окно в полноэкранном режиме. Долгое удержание Esc в Chromium всё равно выходит из полноэкранного режима — это аварийный выход.

## Почему кнопки Windows нельзя убрать

Кнопки рисует оверлей Electron (`titleBarOverlay`, высота 40px). Его создаёт главный процесс приложения (`resources/app.asar` → `lib/main.js`), и у страницы нет к нему доступа. Через preload она умеет только перекрашивать оверлей. Плагины DSH работают либо в отдельном Node-процессе, либо в изолированной странице, поэтому заменить кнопки своими можно только правкой `app.asar` (так делает `dsh-window-control`). Этот плагин `app.asar` не трогает.

## Как он устроен

Только CSS и немного JS в браузерной части (`lib/client.js`). Хэшированные префиксы классов (`mP3x-q_`, `an3WzG_`, `wtg9ga_`) плагин читает в момент работы из `<style data-plugin-css>` самих модулей, поэтому обновления DSH его, скорее всего, не сломают.

Проверка без запуска приложения: `node test/run.mjs`.
