# dsh-quick-switch

Быстрое переключение между сессиями DeepSeek Harness с клавиатуры.

## Как пользоваться

- **Ctrl+Space** в десктопном приложении (в веб-версии **Ctrl+Shift+Space**) открывает палитру поверх окна.
- Набирай название сессии. Поиск нечёткий: начала слов весят больше, имя рабочей папки тоже учитывается, но слабее. Запрос в неправильной раскладке (ЙЦУКЕН вместо QWERTY и наоборот) всё равно находит.
- **↑ / ↓** выбирают строку, **Enter** открывает сессию, **Esc** закрывает палитру.
- При пустом запросе показываются недавно открытые сессии, и предыдущая уже выделена. Поэтому Ctrl+Space, Enter переключает туда и обратно, как Ctrl+Tab.
- После короткой паузы под совпадениями по названию появляются совпадения в тексте переписки (для запросов от трёх символов).
- **Alt+1…9** открывают панели левого сайдбара по порядку.

Все сочетания регистрируются в собственном реестре DSH: они видны по Ctrl+/ и переназначаются там же.

## Настройки

Настроек нет. Список недавних сессий хранится в localStorage приложения.

## Устройство

- `lib/index.js` — хост, ничего не делает: строка в `cordis.patch.yml` нужна только чтобы загрузилась браузерная часть.
- `lib/client.js` — палитра на React из загрузчика модулей DSH, без сборки. Данные и навигация берутся из клиентских сервисов DSH.
- `test/run.mjs` — тесты поиска и ранжирования: `node test/run.mjs`.
